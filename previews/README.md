# README visual QA previews

Generated by:

```bash
python3 scripts/render_previews.py
```

This optional QA utility uses Playwright/Chromium and Pillow. It is **not** required by the GitHub profile generator or scheduled refresh workflow.

The QA harness embeds the generated SVGs as data URIs because the execution sandbox blocks local `file://` / loopback browser navigation. The actual GitHub README uses normal repository-relative SVG paths.

Outputs:

- `desktop-light.png` — 1440 px viewport, light theme;
- `desktop-dark.png` — 1440 px viewport, dark theme;
- `mobile-light.png` — 390 px viewport, light theme;
- `mobile-dark.png` — 390 px viewport, dark theme;
- `preview-sheet.png` — compact four-way parity comparison.

The same run also checks horizontal overflow, reduced-motion animation shutdown across every generated SVG, and SVG text bounds.
