## 🧠 Engineering approach

<table>
  <tr>
    <td width="25%" valign="top">
      <h4 align="center">01 · Model clearly</h4>
      <p align="center">Define ownership, state transitions, permissions, and failure cases before implementation.</p>
    </td>
    <td width="25%" valign="top">
      <h4 align="center">02 · Keep paths lean</h4>
      <p align="center">Cache carefully, batch writes, index hot data, and avoid unnecessary work inside frequent events.</p>
    </td>
    <td width="25%" valign="top">
      <h4 align="center">03 · Persist safely</h4>
      <p align="center">Prefer atomic saves, guarded operations, recoverable state, and explicit shutdown behavior.</p>
    </td>
    <td width="25%" valign="top">
      <h4 align="center">04 · Refine the UX</h4>
      <p align="center">Make configuration understandable and interactions predictable on both desktop and mobile.</p>
    </td>
  </tr>
</table>
