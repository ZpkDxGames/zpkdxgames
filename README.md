Who am I?
I’m Antônio José Tristão Neto, a Brazilian developer and Computer Science student from Uberaba, Minas Gerais. I also have hands-on experience across financial and administrative operations, where organization, accuracy, documentation, and process improvement are essential.
Under the names Tonim and ZpkDxGames, I build Minecraft plugins and practical digital tools with a strong focus on customization, reliability, clean user experiences, and server performance.
I’m currently open to new professional opportunities in technology, software development, administration, finance, and roles where technical and operational thinking work together.
What am I currently working on?
[x] PlexonBackpacks — a tiered backpack plugin for Paper 26.2 with custom player-head items, unique storage IDs, MiniMessage customization, owner binding, inventory safety, and batched persistence.
[x] Plexon DailyRewards — a configurable daily-reward system for Paper 26.2 with group/world-based tiers, MiniMessage GUIs, CSV persistence, claim protection, admin tools, and a developer API.
[x] GhostBlocks — a Vanilla+ building utility that creates visible blocks without collision, supported by categorized GUIs, pagination, persistence, and performance-minded lookups.
[x] PlexonChats — a modern Paper chat-management plugin with local/global channels, private messages, mentions, interactive item sharing, announcements, MiniMessage formatting, and optional Vault/PlaceholderAPI integrations.
[ ] Portfolio and personal projects — continuing to refine my professional portfolio, web interfaces, and tools that connect practical workflows with technology.
