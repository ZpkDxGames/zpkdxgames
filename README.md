I'm **Tonim**, also known as **ZpkDxGames**, a developer and Computer Science student. I build Minecraft server systems, web interfaces and useful tools. I care about the connection between a feature's logic and the experience of using it: clear feedback, reliable state and interfaces people can understand.

**Plexon** brings much of that work together, from independently versioned gameplay modules to shared infrastructure and a browser command center. Alongside it, I work on desktop interfaces, 3D avatars and smaller web projects.

| **[Utility](https://github.com/ZpkDxGames/PlexonUtility)** | Player utilities, HUD feedback and staff controls. |
| **[Tools](https://github.com/ZpkDxGames/PlexonTools)** | Unique, world-activated custom-tool progression. |
| **[Quests](https://github.com/ZpkDxGames/PlexonQuests)** | Joined daily, weekly and milestone objectives. |

| **[Skills](https://github.com/ZpkDxGames/PlexonSkills)** | RPG skills, abilities and progression. |
| **[Keys](https://github.com/ZpkDxGames/PlexonKeys)** | Key identity, virtual balances, physical claims and acquisition provenance. |
| **[DailyRewards](https://github.com/ZpkDxGames/Plexon-DailyRewards)** | Configurable calendar-based reward tracks. |
| **[Crates](https://github.com/ZpkDxGames/PlexonCrates)** | Retired crate implementation, retained as historical source. |
| **[Chats](https://github.com/ZpkDxGames/PlexonChats)** | Communication, Chat Events and Bingo. |
| **[Shops](https://github.com/ZpkDxGames/PlexonShops)** | Player-shop discovery and directory; server item trading remains external. |
| **[Jobs](https://github.com/ZpkDxGames/PlexonJobs)** | Occupations, progression, payouts and player feedback. |
| **[Homes](https://github.com/ZpkDxGames/PlexonHomes)** | Named homes, safe travel and migration tooling. |
| **[Travel](https://github.com/ZpkDxGames/PlexonTravel)** | Spawn, hub, warps, back, TPA and scoped random travel. |
| **[Backpacks](https://github.com/ZpkDxGames/PlexonBackpacks)** | Tiered backpacks with persistent item-specific storage. |
| **[Spawners](https://github.com/ZpkDxGames/PlexonSpawners)** | Recovery and reward policy around WildStacker's authoritative spawners. |
| **[Blacksmith](https://github.com/ZpkDxGames/PlexonBlacksmith)** | Exact-item repair, combine and enchant workstation. |
| **[GPFlags](https://github.com/ZpkDxGames/PlexonGPFlags)** | Claim policy and editing around GriefPrevention. |
| **[GriefPrevention addon](https://github.com/ZpkDxGames/PlexonGriefPreventionAddon)** | Deprecated predecessor; use GPFlags for the replacement. |

**Beyond Plexon:** [GhostBlocks](https://github.com/ZpkDxGames/GhostBlocks) adds collision-free decoration using state-preserving BlockDisplay models and a searchable catalog.
